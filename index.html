Bem-vindo à Aula de HTML e Git

Esta é uma página modelo estruturada com HTML5 semântico e estilizada com CSS interno. Ela serve como ponto de partida ideal para testar o versionamento de arquivos no VS Code e enviar alterações para o GitHub.

Conteúdos Praticados Hoje

  • Estrutura básica de um documento HTML5 (<header>, <main> e <footer>).
  • Criação de listas não ordenadas e parágrafos informativos.
  • Formulários interativos com botões de seleção única (radio buttons).
  • Controle de versão utilizando git init, git add, git commit e git push.
